SB3 Toolchain

@kubohiroya/sb3-toolchain@0.20.0

責務使い方APISchema関連文書

責務と公開範囲

Scratch 3 / TurboWarpのSB3をGit管理できる展開ソースへimportし、検証・決定的な再buildを行うCLIとJavaScript APIです。埋込拡張のversion・SHA-256・API manifestの検証にも対応します。

このページはlibraryのドキュメントです。TurboWarp拡張の独立したpaletteやブロックは提供しません。

使い方

公開済みの完全固定versionを使います。

npm install --save-exact @kubohiroya/sb3-toolchain@0.20.0
sb3-toolchain import tmp/project.sb3 --output app
sb3-toolchain check app
sb3-toolchain build app --output dist/project.sb3

API

入口 責務
importSb3 SB3を展開ソースへimportします。
validateSb3Source 展開ソースのアセット参照や整合性を検証します。
buildSb3 展開ソースからSB3をbuildします。
bundleExtensions 管理対象の埋込拡張を一つの権限単位へ静的bundleします。

全ての公開型・引数はREADMEとsourceを参照してください。

Schemaの正本と公開コピー

このCLIは独立したJSON Schemaの配布元ではありません。展開ソースの形式と検証規則は以下の関連文書を参照してください。
